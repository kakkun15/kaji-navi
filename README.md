# 鍛冶ナビ

ドラゴンクエストX の道具鍛冶で、次に打つ手をすすめる計算機。ブラウザだけで動く(インストール不要)。

## 開く
- [鍛冶ナビを開く](https://kakkun15.github.io/kaji-navi/dist/app.html)
- [鍛冶の早見](https://kakkun15.github.io/kaji-navi/dist/hayami.html)
- [性能テスト(PC 向け)](https://kakkun15.github.io/kaji-navi/dist/bench.html)


- **鍛冶ナビ** `dist/app.html` … 盤面の数字を手で入れると、次に打つ手と大成功の見込み(%)を出す。声で読み上げもする。
- **鍛冶の早見** `dist/hayami.html` … 温度ごとの伸びと会心率の早見。
- **性能テスト** `dist/bench.html` … 計算の強さ(ふつう/最強など)を同じ局で比べる。PC 向け。

対応している商材: まおうの錬金ランプ・超ようせいのひだね・光の鍛冶ハンマー・光のフライパン・光のさいほう針(仮の計算)。

光のさいほう針は許容誤差が 0(2マスとも理想値ぴったりで大成功)で、ほかの商材と同じ学習では打ち方が身につかなかった。今は手で作った打ち方(会心は理想値を越えないので、越えない所まで寄せてから、ねらい打ちの会心で理想値に止める)で推奨を出している。見込み% はその打ち方で何回も打ってためした平均。

## 使い方
`dist/app.html` をブラウザで開く。商材を選んで、ゲームの盤面に合わせて数字を入れ、すすめられた手を打ったら結果を入れる、のくり返し。

- 計算の強さ「最強」は PC 向け(全スレッドを使う)。スマホは「ふつう」。
- 学習は 職人Lv75・光の鍛冶ハンマー★3 の条件で行った。ほかの条件でも使えるが、見込み% は目安。
- 必殺(ヘパイトスの炎)は「必殺」ボタンで入れる。
- 集中力の欄は今の値(押すと直せる)。打ち始めの集中力は、その下の「最初の値を変える」で変える。

## このツールがしないこと
- ゲームの画面を読み取らない。ゲームに入力しない・自動で打たない。数字は全部手で入れる。
- 外にデータを送らない(設定はブラウザの localStorage に置くだけ)。

## 中身
| 場所 | 中身 |
|---|---|
| `src/core.js` | 技・威力・会心率・地金特性 |
| `src/game.js` | ゲームの再現(局面・打てる手・結果の分布・判定) |
| `src/value.js` | 局面の見積もり(小さなニューラルネット)と先読み |
| `src/pool.js` | PC 向けの並列の読み(Web Worker) |
| `src/mlp.wat` | ネットの掛け算(WebAssembly SIMD) |
| `src/rule0.js` | 許容誤差 0 の商材(光のさいほう針)の仮の打ち方 |
| `src/voice.js` | 読み上げの声(VOICEVOX:ずんだもん) |
| `train/` | 学習(自己対戦)と計測のスクリプト、使っている重み |
| `docs/仕様.md` | ゲームの仕組みと出典 |
| `docs/計算の設計.md` | 計算の考え方 |

作り直す: `python3 build.py`(`src/` の計算と `train/` の重みを各ページに埋め込んで `dist/` に出す)。
試験: `node tests/core.test.js`。
