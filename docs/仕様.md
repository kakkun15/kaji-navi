# 鍛冶ナビ 仕様: ゲームの仕組み

この文書は、鍛冶ナビの計算のもとにした「ゲームの仕組み」のまとめ。
元にしたのは公開されている攻略情報と、実機での観察だけ。

各項目の末尾の [S1] などは出典(下の一覧)。[実機] は利用者の観察、[要確認] はまだ裏付けが弱いもの。

---

## 1. 盤面
- 横2列 × 縦3行(最大4行)のマス。商材ごとに使うマスと、各マスの成功ゾーン(下限〜上限)が決まっている。 [S1]
- 各マスには、ゾーンの中のどこかに見えない「理想値」があり、毎回ランダム。 [S3][S4]

## 2. 温度と集中力
- 開始温度は 1000℃。 [S1]
- 叩く技・特技は温度を 50℃ 下げる。火力上げは +300℃、冷やし込みは −300℃、熱風おろしは −150℃。 [S1]
- 温度が 0℃ になると強制終了。 [S1]
- 集中力は職人レベルとハンマーで決まる上限から始まり、技ごとに減る。

## 4. 威力(1回で伸びる量)
- 1000℃で「たたく」は 12〜18 の7通りのどれか(等確率)。 [S2]
- 式(x = 温度、2000℃で頭打ち、n = 12〜18、y = 技の倍率、z = たたき変化、w = 会心):
  `w × ceil( z × ceil( (0.5 + 0.0005x) × ceil(n × y) ) )`  [S2]
  - 端数はそれぞれの段で切り上げ。
  - 計算機の小数の誤差を避けるため、(0.5 + 0.0005x) は (1000 + x) / 2000 として整数で計算する。
- 例外: n=15 の時だけ、倍率1.2(上下系)は 18 ではなく **19**、倍率0.8(みだれ打ち)は 12 ではなく **13** になる。
  1000℃の上下打ちは 15・16・17・19・20・21・22(18 は出ない)。 [S6]
  - この例外を入れると、[S6] の表(2000〜50℃・50℃刻み・7通り全部)の読める279行が全部一致する(tests/core.test.js)。

## 5. 会心
- 会心は威力が2倍。その範囲の中に理想値があれば、理想値でぴったり止まる(本会心)。 [S3]
- 会心率 = 道具会心率 × (1 + ボーナスの合計)。ボーナスは足し算。 [S5]
  - ねらい系: +600%(約7倍)。 [S5]
  - 集中力変化の会心ターン: +400%(5倍)。 [S5]
  - 両方: +1000%(11倍)。 [S5]
  - 威力会心率上昇の光ったマス: [要確認] 公開の実測なし。仮に +400%(利用者の情報)。
- 道具会心率 = 職人スキル(Lv10で0.1%・Lv20で+0.2%・Lv30で+0.3%、計0.6%) + コツ1.0%(「らしい」) + ハンマー。 [S1][S5]
  - ハンマーの基礎: 銅1・鉄1.5・銀2・プラチナ2.5・超3・奇跡3.3・光3.6(%)。できのよさ ★+0.1・★★+0.2・★★★+1.0。 [S1]
  - 例: Lv30以上・光★3 = 0.6 + 1.0 + 4.6 = 6.2%。ねらい打ち 43.4%。 [S5]

## 6. 地金特性(温度で効果が変わる)
効果は「打つ前の温度」で決まる。開始直後(1手目)は乗らない [実機]。
- 集中力変化: 400の倍数で消費 0.5倍。200の倍数(400以外)で消費 1.5倍・会心率アップ(+400%)。 [S1][S5]
- たたき変化: 400の倍数で威力 2倍。200の倍数(400以外)で 0.5倍。 [S1][S2]
- 威力会心率上昇: 200の倍数の時、ゾーンに届いていないマスが1つランダムに光る。光ったマスは威力2倍・会心率アップ。 [S1]
- メーター減少(戻り): 200の倍数の時、1マスの値が 12〜16 戻る。ゾーン内のマスと 0 のマスは変わらない。 [S1]
  - [要確認] どのマスが戻るか: [S1] は「最も伸びているゲージ」。利用者の観察とすり合わせる。

## 7. 誤差と大成功
- ゾーン内のマスの誤差は、理想値との差が5以上でも 4 扱い。 [S3][S4]
- ゾーン外(届いていない・超えた)のマスは、必ず誤差9以上扱い。 [S1][S4]
- 誤差の合計が、商材の許容値以下なら大成功。マスの数で決まる(下の表、[S3])。

| マス数 | 例 | 大成功の誤差合計 |
|---|---|---|
| 2 | さいほう針 | 0 |
| 3 | ルアー | 0〜2 |
| 4 | 錬金ランプ | 0〜3 |
| 5 | 鍛冶ハンマー | 0〜5 |
| 6 | 錬金ツボ・超ようせいのひだね | 0〜7 |
| 7 | フライパン | 0〜9 |

[要確認] 同じマス数でも形で違うという説(ヤリ・ツメなど)。8マスの値。
