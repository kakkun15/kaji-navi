# 鍛冶ナビ 推奨手の計算の設計

公開されている攻略情報と実機での観察をもとに、1から書いた。

## 1. 計算の考え方
1. **ゲームの再現(src/game.js)**: 局面は「マスの値・理想値の見当・温度・集中力・光ったマス・1手目か」。
   - 理想値の見当はゾーンの値ごとの確率。会心の結果(止まった・2倍進んだ・動かなかった)でしぼる。
   - ゾーンに入ったマスも叩ける(超える危険は計算に入る)。
2. **局面の見積もり(src/value.js)**: 局面の特徴(マスごと16個・全体15個)→ 小さなニューラルネット(64-64)→ 大成功の確率。
   - 「今やめた時の大成功の確率」は見当から正確に計算でき(マスごとの誤差の分布を掛け合わせる)、見積もりはこれより下にならない。
3. **推奨手**: 打てる手を全部試し、打った後の局面の見積もりの期待値が一番高い手(1手先読み)。
   1マスの手は結果を全部数える。複数マスの手は12通り引いて平均する。光ったマスは打った後に決まるので候補ごとに平均する。
   PC では上位4手だけ2手先まで読む(evalActs2)。
4. **学び方(train/train.js)**: 商材ごとに学ばせる。
   - 最初に、単純な規則の打ち手(train/scripted.js)で最後まで打った結果を覚えさせる(足がかり)。
   - その後は自己対戦の繰り返し: 今の見積もりで1手先読みして打ち、各局面の「一番良い手の値」と「実際に勝ったか」を
     混ぜた値(λ=0.7)を目標に学び直す。終盤から序盤まで広くばらまいた局面も混ぜる。

## 2. 試験・計測
- `node train/compare.js <商材> <重み> <局数> <種> [深さ]` 成績。
